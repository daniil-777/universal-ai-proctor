## User-selected footage for visual analysis

Cueveris also supports general browser screen sharing. The user chooses a tab, window or display using the browser's picker and explicitly starts analysis. This is a route for footage the user owns, has permission to process, or otherwise has a lawful basis to analyse. Selecting a window is not evidence of copyright permission, and the feature does not grant reuse rights in whatever appears on that window.

Selected images can be transmitted to the configured AI provider for analysis. The sharing instructions must make that processing clear. Camera or screen-sharing permission is permission to capture the selected source for the app. It does not grant a licence from the source's author, confer endorsement, or permit public redistribution. Users can stop sharing through the browser or application controls.

The screen-sharing feature uses the user's selected browser capture. It does not download a YouTube stream, read pixels out of the embedded player, bypass restrictions, or treat a Google AI Ultra or YouTube Premium subscription as a reuse licence. This public Leica walkthrough does not exercise visual analysis on Leica frames.
