# Process Guide frontend

React/TypeScript workspace for video, camera and document-based process guidance.

See [the application README](../README.md) for startup, configuration and verification. Use Node 22 or newer; Node 24.18 is selected by the project configuration on this Mac.

`npm run dev` starts the development interface at http://localhost:8180 and proxies API requests to port 8101. The built app and API run together at http://localhost:8101 through the root launcher.
